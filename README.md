# FluxHub — Игровая платформа как Steam

FluxHub — полноценная веб-платформа для публикации и игры в HTML/JS игры. Дизайн в стиле Steam + неон, glassmorphism, тёмная тема.

## 🚀 Фишки
- **Магазин** с категориями, поиском, сортировкой, геро-блоком и топом
- **Библиотека** — сохраняй игры, играй в 1 клик
- **Публикация игр**: HTML/CSS/JS + лого + скриншоты → отправка на модерацию
- **Игра в iframe** с fullscreen, изолированный sandbox
- **Лайки, комменты, счётчики plays, теги**
- **Авторизация**: регистрация/вход, профили, аватары
- **Админ-панель**:
  - Модерация игр (тест → одобрить/отклонить с причиной)
  - Управление юзерами: выдать/забрать админку, баны на время (1h/24h/7d/30d/1y), разбан
  - Статистика, все игры, удаление
  - `cursed_dev` — **superadmin** 👑 (нельзя забанить/забрать роль), логин `cursed_dev / 12345678`
  - Все админы могут модерить
- **JSONbin.io** синхронизация: `6a949376da38895dfe2401aa` — автосохранение, локальный кэш как fallback
- Допы: toast-уведомления, анимированные частицы, адаптив, демо-игры

## 📁 Структура
```
index.html
css/style.css
js/config.js    — JSONbin ключи + SUPERADMIN
js/storage.js   — загрузка/сохранение DB (JSONbin + localStorage)

js/games.js     — публикация, каталог, библиотека, лайки, комменты, плеер
js/admin.js     — модерация, юзеры, статистика
js/app.js       — роутер, тосты, инициализация
```

## 🎮 Как опубликовать игру
1. Войди → нажми **Опубликовать**
2. Введи название, описание, категорию, теги
3. Загрузи лого (600×400) и скриншоты (16:9)
4. Вставь HTML/CSS/JS (демо-шаблон по кнопке)
5. Согласись → **Отправить на модерацию**
6. Админ в **Админка → Модерация** может **Тест** (открыть iframe), **Одобрить** или **Отклонить** с причиной
7. Одобренная игра появляется в Магазине

## 🛡️ Модерация
- `pending` → видно только автору + админам
- `approved` → в магазине для всех
- `rejected` → видно автору с причиной, можно переопубликовать новую версию

## 🧪 Локальный запуск
Просто открой `index.html` через Live Server (из-за `fetch` к JSONbin нужен http). Или:
```bash
npx serve .
```
